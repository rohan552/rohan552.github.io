Privacy policy

Last updated: 26 November 2026

This policy covers "Vyomiko uploader", a private tool used only by the owner of the Vyomiko channels.

What the tool accesses

With the owner's permission, through Google sign-in, the tool uses the YouTube Data API to upload videos, set thumbnails and captions, and read basic channel and video statistics for the owner's own channels.

What we store

The sign-in token is stored only on the owner's own computer. We do not collect, sell or share personal information about anyone. We do not access other people's YouTube accounts.

Google API data

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions: message the Vyomiko channel on YouTube.
